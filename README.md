## Что здесь

ДЗ1: подключаемся к учебной базе ПРАЙМ и считаем диагностику по одному участку данных — таблица service_usage, сегмент desktop, окно 01.04.2025–30.04.2025: объём и чистоту выгрузки, распределение активности по дням недели, самых активных участников и три пиковых по нагрузке дня, устойчивость обработки к «грязным» строковым значениям. Отдельно — два открытых исследования: насколько надёжна оценка по выборке в 1000 участников на фоне всего сегмента и чем сегмент desktop отличается от соседних сегментов той же таблицы.

## Как запустить

Нужны [Git](https://git-scm.com/) и [uv](https://docs.astral.sh/uv/).
Python отдельно ставить не нужно — его поставит uv.

```bash
git clone git@github.com:ВАШ_ЛОГИН/prime-monitor.git
cd prime-monitor
uv sync
```

Доступ к учебной базе выдаёт бот курса по команде `/db`. Полученную строку
подключения кладём в `.env`:

```bash
cp .env.example .env
# и вписать в .env строку из бота
```

Проверка, что всё встало:

```bash
uv run python -c "from prime.config import get_engine; print(get_engine().connect().execute(__import__('sqlalchemy').text('select current_user')).scalar())"
```

Запуск JupyterLab:

```bash
uv run jupyter lab
```
